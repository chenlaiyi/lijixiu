# 2026-10-25 小程序审核整改

依据管理员提供的驳回截图，整改三个问题：协议默认同意、登录页混淆官方元素、首次进入即要求授权登录。

- 默认入口改为启动页：游客进入服务首页，已登录用户仍按身份进入工作台。
- 首页不再强制跳转登录，不读取游客私有订单；残留用户缓存且无 token 时同样不请求私有接口。
- 可以先浏览服务类别和报修表单；游客提交报修时才提示登录，并允许继续浏览。
- 登录页移除“微信登录”等可见文案及对应图标，统一使用“手机号快捷登录”。保留平台提供的真实手机号授权组件。
- 用户协议及隐私政策可独立打开阅读；协议选项默认未选中，可以取消，所有快捷、短信、密码及体验登录入口均检查主动勾选。未勾选时不发送短信、不请求登录、不启动手机号隐私授权。
- 删除“登录即表示同意”和协议中的“继续使用即视为接受”表述，提供暂不登录浏览服务入口。

验证：test_review_consent.js、test_multi_role_miniprogram.js（12 项）、test_bill_revision_miniprogram.js 均通过。小程序 CI 编译上传成功，开发版本为 2026.10.25.1；本次只修改小程序，无后端改动或服务重启。已有 API 健康检查 HTTP 200。
