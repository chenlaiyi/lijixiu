# 2026-11-01 家政预约页类目审核整改

## 原因与整改

用户提供的审核截图指出“发布月嫂需求”页提供用户自定义文字、图片等内容发布和分享，要求补充社交-笔记类目。本次将该业务收敛为家政服务预约申请，所有用户使用相同功能，不按审核身份隐藏能力。

- 月嫂与保姆统一使用“服务预约”“提交预约申请”表达，页面明确资料仅用于门店联系及服务匹配、不公开展示、不支持转发。
- 删除预约页补充说明自由文本、录音、照片上传及其隐私授权/录音器逻辑；保姆的时间、工作内容改为预设时段与服务项目多选。保留联系人、电话、地址库选择、日期、预算及必要服务选项。
- 移除该页 share.create 分享处理，在 onLoad/onShow 隐藏好友及朋友圈分享，并在页面配置关闭分享。分享不会带出预约内容。
- 提交使用固定的月嫂/保姆预约描述和结构化 detail_json。列表仅展示当前用户的预约状态及固定服务名称，不展示旧自由说明。
- 此次仅修改小程序；未修改后端、业务数据或服务端配置，未重启任何服务。其他服务的报修流程、推荐码及地址库功能保留。

## 验证与交付

- tests/test_domestic_reservation_ui.js：月嫂/保姆结构化提交、地址编号、固定描述、取消媒体及分享、重复提交及缺失信息保护。
- tests/test_domestic_reservation_privacy.py：客户仅查询本人预约，跨客户查询返回 403。
- test_address_fields.js、test_referral_ui.js 回归通过；JavaScript 语法和 Git diff 检查通过。
- miniprogram-ci 最终编译上传成功：开发版本 **2026.11.01.2**。未代用户提交审核或正式发布。

## 建议审核备注

家政页面已整改为月嫂/保姆服务预约申请：已取消自由图文、语音内容制作和上传，取消预约页转发与朋友圈分享；仅提交联系人、服务地址、日期及结构化服务选项，用于门店联系确认和服务匹配。客户只可查看自己的预约记录，无公开用户内容展示、笔记发布或社区交流功能。

本次整改不替代微信公众平台对实际服务类目的判断；由用户按最终页面功能手动提交审核。
