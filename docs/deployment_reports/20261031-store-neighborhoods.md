# 2026-10-31 门店区县归属与小区服务范围

用户确认：建门店和录入地址只选城市/区县，不选街道社区；同一区县可有多店，小区决定订单实际归属。

- 本项目现有区域规则为 level=1 城市、level=2 区县。门店新增/修改仅接受有城市父级的区县。
- 门店每行新增“修改”，弹窗修改名称、所属区县、店长、城市经理、默认师傅和备注，点击“保存门店”后生效。
- “分配小区服务范围”按行维护小区/分期名称，保存完整替换本店范围；空列表可清空。其他门店已占用的小区拒绝重复分配，须先从原门店移除再分配。
- 新小区为 ServiceArea 的 estate 类型，唯一编码包含城市/区县/名称，继续使用已有分配、审计和订单路由链路。小区修改不改写历史订单快照。
- 调整门店区县前，需清空原服务范围；调整负责人或小区归属时同步标准地址的未来接单门店/业务负责人，保留历史订单字段。
- 后台地址录入仅显示城市/区县，填写的小区必须已分配有效门店。客户端沿用地址目录接口，不需要修改小程序包。
- 原政府街道/社区库保留为参考，原有社区服务范围在窗口显示供人工迁移。未自动猜测社区下的小区，也未把带楼栋的旧地址字符串强行拆分。旧批量分配接口不能再将社区或其他区县分配给新门店。
