# 2026-10-31 区域修改、保存与删除

- 区域列表每行提供“修改”“删除”。修改弹窗集中维护名称、城市/区县层级、上级城市及负责人，点击“保存区域”生效；负责人可清空。
- 城市不得设置上级；区县必须选择城市作为上级，禁止自引用。新增/变更区域时拒绝同上级同层级同名记录。
- 删除仅平台管理员可调用。遍历模型中所有 regions.id 引用，存在下级、门店、订单、师傅、地址等关联时返回 409 并列明关联数量。
- 正在被引用的区域允许维护负责人，但不能直接改变地理名称、层级或上级，避免破坏门店区县与小区匹配。需先调整关联。
- 创建和编辑提交增加前端进行中保护；已有重复区域不自动合并或删除。
