# 2026-10-24 地址链路与未支付服务单合并发布

## 功能

- 客户下单、代客下单、客户地址簿、门店地址库、H5 使用统一的城市/区域、小区、门牌号。
- 示例：厦门市/海沧区；未来海岸-蓝月湾一期；嵩屿北五里23号2101室。
- 服务区域由后端按当前有效归属分配门店；未匹配小区不能沿用旧门店。历史订单保留原地址和门店快照。
- 兼容旧楼栋、单元、房号数据，新增 door_number；无破坏性数据迁移。
- 未支付服务单允许师傅修改重提；客户按最新金额支付。旧支付单关闭、已支付及部分支付拦截、版本冲突检查保留。店长审核与工资逻辑不变。
- 合并服务器既有登录、手机号、推广及支付代码，避免部署旧本地基线覆盖线上功能；恢复身份切换 business_role 请求契约。
