## 第一条 协议范围与定义

1.1 **本协议**是您与平台运营方之间就使用本平台(包括但不限于微信小程序"H5 工作台"、管理后台、相关 API 接口)所订立的协议。

1.2 **用户**指通过本平台注册、登录、使用本平台各项服务的自然人、法人或其他组织,包括但不限于:
   - **客户**:发起维修需求、接受维修服务的用户
   - **师傅/服务人员**:提供上门维修服务的个人或团队
   - **门店**:为师傅提供调度、薪酬管理的实体
   - **其他角色**:客服、运营、平台管理员等

1.3 **本平台**指由运营方运营的"立即修"上门维修 O2O 平台,包括但不限于微信小程序、移动端 H5、管理后台及配套服务。

## 第二条 服务内容

2.1 平台提供以下服务:
   - 维修需求发布与匹配
   - 上门维修服务撮合
   - 服务费用结算与支付
   - 师傅/服务人员管理
   - 投诉与售后处理
   - 钱包与提现服务
   - 其他平台运营方不时提供的服务

2.2 平台本身不直接提供维修服务,仅为供需双方提供撮合与信息中介服务。

## 第三条 用户注册与账户管理

3.1 用户应使用真实有效的手机号码、身份信息进行注册。

3.2 用户应妥善保管账户、密码及验证码,**不得将账户出借、转让**。因账户保管不善造成的损失,由用户自行承担。

3.3 用户发现账户被盗用或存在安全漏洞的,应及时联系平台。

3.4 平台有权对违反法律法规、本协议或平台规则的账户进行冻结、注销。

## 第四条 用户行为规范

4.1 用户应遵守中华人民共和国法律法规,不得利用本平台从事违法违规活动。

4.2 用户不得:
   - 发布虚假维修需求或欺诈信息
   - 恶意刷单、套现、洗钱
   - 侵犯第三方知识产权、隐私权、名誉权
   - 干扰平台正常运行(如 DDoS 攻击、注入攻击)
   - 散布谣言、淫秽、暴力、恐怖信息

4.3 师傅/服务人员应:
   - 持有合法有效的从业资质
   - 按约定时间、地点上门提供服务
   - 保证服务质量,提供合理保修
   - 不得向客户索取约定外的费用

## 第五条 服务费用与支付

5.1 平台服务费用以平台公示或双方约定为准。

5.2 客户应在服务完成后按约定方式支付费用。

5.3 师傅/服务人员的报酬由平台根据服务订单计算,通过平台钱包结算。

5.4 提现规则、提现手续费、提现到账时间以平台公示为准。

5.5 平台有权对异常订单进行风控审查,包括但不限于:
   - 同一用户短期内多次发起大额提现
   - 短时间内多次修改账户信息
   - 钱包余额与对账不一致

## 第六条 资金安全

6.1 平台建立资金安全机制,包括但不限于:
   - 钱包余额与账本逐日对账
   - 提现审批与人工审核
   - 异常交易告警

6.2 用户理解并同意,平台根据反洗钱法律法规,有权对可疑交易进行冻结、延迟处理、报告主管部门。

6.3 因司法机关、行政机关要求,平台有权配合提供用户身份信息、交易记录。

## 第七条 知识产权

7.1 平台所有内容(包括但不限于文字、图片、代码、UI 设计、商标)的知识产权归平台运营方所有。

7.2 用户未经授权,不得复制、传播、修改平台内容。

7.3 用户在平台发布的评价、晒单等内容,授予平台非独家、可转授权的使用权。

## 第八条 隐私保护

8.1 平台重视用户隐私,具体隐私政策详见《立即修平台隐私政策》。

8.2 平台收集、使用用户信息遵循"最小必要"原则,详见隐私政策。

## 第九条 平台责任限制

9.1 平台作为信息中介,不对以下情形承担责任:
   - 师傅/服务人员因故意或过失造成的财产损失、人身损害(由相关责任方承担)
   - 客户故意隐瞒、虚构维修需求造成的纠纷
   - 不可抗力(自然灾害、疫情、政府行为等)造成的中断或损失

9.2 在法律允许的范围内,平台对用户承担的最高责任不超过用户因使用本平台而向平台支付的费用(如有)。

## 第十条 协议变更与终止

10.1 平台有权根据法律法规变更、业务调整等情况修改本协议,修改后的协议在生效日期起替代原协议。

10.2 用户不同意修改的,可在生效日期前停止使用本平台;继续使用的,视为接受修改。

10.3 用户可随时申请注销账户;账户注销后,本协议终止,但已发生的交易仍按原协议处理。

## 第十一条 法律适用与争议解决

11.1 本协议适用中华人民共和国法律(不含港澳台地区法律)。

11.2 因本协议产生的争议,双方应友好协商;协商不成的,提交平台运营方所在地有管辖权的人民法院诉讼解决。

## 第十二条 其他

12.1 本协议如有任一条款被认定为无效,不影响其他条款的效力。

12.2 本协议所有标题仅为阅读方便,不影响条款解释。

12.3 平台对本协议拥有最终解释权。
