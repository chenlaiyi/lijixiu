# 合规资质与备案申请指南

> ⚠️ **法律免责声明**:本指南为通用说明,实际办理以当地主管部门(工信部 / 通信管理局 / 市场监管局 / 商务局)最新规定为准。**正式办理前请咨询专业律师或资质代办机构**。

立即修作为上门维修 O2O 平台,在中华人民共和国境内运营,需具备以下资质:

## 一、必备资质(不可缺)

### 1.1 ICP 备案(网站备案)

**适用**:任何在境内提供互联网信息服务的网站/App/小程序后端 API。

**办理机关**:工信部 / 当地通信管理局

**办理入口**:[https://beian.miit.gov.cn/](https://beian.miit.gov.cn/)

**办理条件**:
- 主体为在中国境内注册的法人(公司)
- 有境内服务器(已部署)
- 有域名(已注册,实名认证)

**办理流程**:
1. 域名实名认证(在域名注册商处)
2. 服务器接入商(阿里云/腾讯云等)提交备案
3. 主体负责人/网站负责人手机号核验
4. 管局审核(7-20 个工作日)
5. 备案成功,获得备案号(京ICP备XXXXXXXX号-X)
6. 网站底部展示备案号 + 链接到工信部备案系统

**展示位置**(必须):
- `h5/index.html` 底部
- `admin-web/index.html` 底部
- 小程序"设置 → 基本设置"配置 ICP 备案号
- 后端 API 响应头(可选)`X-ICP-License`

**对本项目代码影响**:
- `h5/index.html` 加 `<a href="https://beian.miit.gov.cn/">京ICP备XXXX号</a>`
- `admin-web/index.html` 同上
- `miniprogram/app.json` 或 `project.config.json` 加 `icp`

### 1.2 营业执照(必备前置)

- 公司主体:有限公司(自然人独资 / 多人合资均可)
- 经营范围:必须包含以下任一:
  - "家政服务" / "维修服务" / "居民日常服务"
  - "信息咨询" / "信息技术服务" / "互联网信息服务"
  - **增值电信业务经营许可证(见下)** 如果涉及经营性互联网信息服务

**如果没有公司**:需先注册公司(7-15 个工作日,代办约 500-2000 元)。

### 1.3 增值电信业务经营许可证(ICP 经营许可证,商用必办)

**适用**:通过互联网向上网用户有偿提供信息或者网页制作等服务活动。**上门维修撮合收费 = 经营性互联网信息服务**。

**办理机关**:工信部 / 当地通信管理局

**办理条件**(基础):
- 公司主体(注册资本不低于 100 万人民币,跨地区 1000 万)
- 公司为内资(外资需走 VIE 架构)
- 3 名员工社保(各地有差异)
- 有必要的场地、设施

**办理流程**:
1. 工商注册(拿到营业执照)
2. ICP 备案完成
3. 准备 3 名员工社保证明、场地证明
4. 提交申请到当地通信管理局
5. 受理 → 实质审查 → 颁发(60-90 工作日)
6. 业务范围标注:"信息服务业务(仅限互联网信息服务)"

**耗时**:3-6 个月

**对本项目的影响**:
- 商业模式涉及**撮合收费**(抽佣)→ 必须办
- 如果仅"免费发布信息 + 师傅自接单" → 可能不需要
- 我们的代码目前**是抽佣模式**(订单有 platform_fee)→ 必须办

**没有证的运营风险**:
- 通信管理局罚款 1-10 万
- 应用市场下架
- 微信小程序拒绝审核
- 银行账户冻结

## 二、强烈建议资质

### 2.1 支付业务许可证(单笔超 5 万或月超 20 万)

**触发条件**:
- 用户支付给平台的金额累计超过平台自有资金 → 视为"代收代付"
- 平台留存沉淀资金超过 5 万 / 20 万

**我们目前**:
- 微信支付 V3 走微信商户号 → 商户号本身需要 ICP 经营许可证
- 钱包里有沉淀资金(用户未提现)→ 严格说需要"支付业务许可证"

**建议**:
- 钱包余额尽量不留存(T+1 自动提现 / 自动转账)
- 或接入合规的第三方支付 / 银行存管

### 2.2 信息系统安全等级保护备案(等保)

**适用**:收集用户个人信息的网络运营者(基本都要做)

**级别**:
- **等保 2.0 二级**:用户量 1-50 万,普通系统
- **等保 2.0 三级**:用户量 50 万以上,或涉及金融、医疗、社保等敏感数据

**办理机构**:公安部认证的测评机构(咨询本地)

**耗时**:1-3 个月测评,1 个月备案

**费用**:二级约 5-10 万,三级约 10-30 万

**对本项目**:
- 上线初期 1 万用户 → 二级即可
- 商用规模化 → 必须三级

## 三、特定业务额外资质

### 3.1 师傅 / 服务人员

- **特种作业证**:电工作业(高压/低压)、焊接、登高 → 法律强制
- **职业资格证**:电工、钳工、空调维修工等(部分职业已取消强制)
- **健康证**:家政(月嫂、保洁)需要

**平台责任**:
- 上门服务前**核验师傅的特种作业证**
- 平台展示师傅的"持证"标识,建立用户信任
- 保险:为师傅购买意外险(团体意外险 / 雇主责任险),用户购买家电维修险

### 3.2 营业执照(师傅个人)

部分城市要求上门维修师傅办理**个体工商户营业执照**或挂靠家政公司。

### 3.3 月嫂 / 家政(如果做)

- **家政服务经营许可证**(部分城市要求)
- 师傅需持**家政服务证** / **育婴师证** / **母婴护理证**

**已经写好的模板**(见 `docs/legal/`):
- `user-agreement.md` — 用户服务协议
- `privacy-policy.md` — 隐私政策

**落地动作**:
1. 律师审核 → 修改
2. 后端增加**协议版本管理**(用户每次登录 / 协议变更时重新确认)
3. 小程序登录页加勾选 + 链接
4. H5 登录页加勾选 + 链接
5. App 首次启动展示

**审核要求**(微信小程序):
- 必须在"设置-服务类目"上传《用户协议》《隐私政策》
- 协议必须能完整展示(不能折叠)
- 协议必须明确数据收集与使用
