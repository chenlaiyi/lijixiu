## 一、我们如何收集和使用您的个人信息

### 1.1 账号注册与登录

| 信息类型 | 收集目的 | 收集方式 |
|---|---|---|
| 手机号码 | 账号注册、身份核验、订单通知 | 用户主动提供 |
| 微信 openid / unionid | 微信生态登录 | 微信小程序 SDK 回调 |
| 头像 / 昵称 | 展示个人资料(可选) | 用户主动设置或微信授权 |
| 位置信息(可选) | 匹配最近师傅、上门导航 | 用户主动授权后获取 |

### 1.2 服务使用

| 信息类型 | 收集目的 |
|---|---|
| 维修需求描述(文字/图片/语音/视频) | 派单、师傅准备工具物料 |
| 联系人 / 联系电话 | 师傅上门联系 |
| 上门地址(精确到楼栋/门牌) | 师傅导航、客户回访 |
| 订单记录(金额/时间/状态/师傅评价) | 平台运营、售后服务、纠纷处理 |
| 服务单信息(维修项/材料费/工时) | 价格确认、保修记录 |

### 1.3 支付与钱包

| 信息类型 | 收集目的 |
|---|---|
| 微信支付订单号、交易流水号 | 支付凭证、争议处理 |
| 钱包余额、提现记录、银行卡号(可选) | 资金结算、合规审计 |

### 1.4 设备与日志

| 信息类型 | 收集目的 |
|---|---|
| 设备型号 / 系统版本 / 微信版本 | 兼容性优化、故障排查 |
| IP 地址 / 访问时间 / 访问页面 | 安全防护、运营分析 |
| 设备标识(OAID / IDFA) | 唯一标识、推送(用户授权后) |

### 1.5 客服与售后

| 信息类型 | 收集目的 |
|---|---|
| 投诉 / 申诉内容(文字/图片/录音) | 纠纷处理、平台改进 |

## 二、我们如何使用 Cookie 和同类技术

2.1 我们使用 Cookie、Local Storage 等技术记录您的登录状态、偏好设置。

2.2 您可以通过浏览器设置或设备设置关闭部分跟踪,但关闭后可能影响本平台的正常使用。

## 三、我们如何共享、转让、公开披露您的个人信息

### 3.1 共享原则

- **最小必要**:仅在为提供您所需服务所必需时共享
- **明确告知**:共享前会告知您接收方的名称、联系方式、处理目的、方式
- **单独同意**:涉及敏感个人信息(身份证、银行卡、生物识别、健康信息、行踪轨迹等)时,需取得您的单独同意

### 3.2 共享场景

| 接收方 | 共享信息 | 目的 |
|---|---|---|
| 师傅/门店 | 您的姓名、电话、上门地址、维修需求 | 提供上门服务 |
| 微信支付 | 订单号、金额 | 支付结算 |
| 短信服务商 | 手机号 | 验证码、订单通知 |
| 云服务商(腾讯云/阿里云) | 加密后的数据 | 数据存储与计算 |
| 监管机关 | 按法律法规要求 | 配合监管 |

### 3.3 转让

我们不会将您的个人信息转让给任何第三方,除非:
- 获得您的明确同意
- 涉及合并、收购、破产清算时(我们会要求继受方继续受本政策约束)

### 3.4 公开披露

我们仅在以下情况下公开披露:
- 获得您的明确同意
- 法律法规要求、诉讼争议、政府强制命令

## 四、您的权利

您对自己的个人信息享有以下权利:

| 权利 | 说明 | 行使方式 |
|---|---|---|
| **知情权** | 了解我们如何收集、使用您的信息 | 本政策已告知 |
| **决定权** | 同意或拒绝非必要信息的收集 | 在授权弹窗中选择 |
| **查询 / 复制** | 查看您的个人信息 | 平台内"我的-个人信息" |
| **更正 / 补充** | 更正不准确或不完整的信息 | 平台内"我的-编辑"或联系客服 |
| **删除** | 删除您的个人信息 | 平台内"我的-注销" |
| **撤回授权** | 撤回对某项信息的收集授权 | 平台内或系统设置 |
| **注销账户** | 永久删除账户及关联数据 | 平台内"我的-注销" |
| **投诉举报** | 对个人信息处理活动投诉 | 客服电话 / 邮箱 |
| **解释说明** | 要求我们对处理规则进行解释 | 联系客服 |

## 五、我们如何保护您的个人信息

5.1 **技术措施**:
   - HTTPS 加密传输
   - 数据库加密存储(密码 bcrypt / argon2 哈希)
   - 钱包/支付数据加密字段存储
   - 定期安全扫描与渗透测试

5.2 **管理措施**:
   - 内部权限分级(平台管理员 / 客服 / 财务等不同权限)
   - 操作留痕(所有 admin 操作写入 audit log)
   - 定期员工合规培训

5.3 **应急措施**:
   - 个人信息泄露事件应急预案
   - 24 小时内通知监管部门与受影响用户

## 六、未成年人保护

6.1 本平台主要面向成年人提供服务。

6.2 如您为未成年人(18 周岁以下),请在监护人陪同下阅读本政策,并在取得监护人同意后使用本平台。

6.3 我们不会主动收集未成年人个人信息。如发现,会立即删除。

## 七、您的个人信息存储

7.1 **存储地点**:中华人民共和国境内(法律法规允许的跨境传输除外)。

7.2 **存储期限**:
   - 账号信息:账号存续期间,注销后 30 日内删除(留 30 日恢复期)
   - 订单/支付记录:**至少 3 年**(电商法、税务法要求)
   - 资金流水(ledger / wallet):**至少 10 年**(反洗钱法要求)
   - 投诉处理记录:至少 3 年

7.3 超过存储期限后,我们将删除或匿名化处理。

## 八、本政策如何更新

8.1 我们可能根据业务调整、法律法规变化更新本政策。

8.2 重大变更将通过站内信、弹窗等方式告知,您可在变更生效前选择是否同意。

8.3 不同意变更的,可停止使用本平台并申请注销。
