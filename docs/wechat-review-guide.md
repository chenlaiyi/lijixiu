`/api/v1/auth/review-login` 需要 `.env` 里同时配置 `WECHAT_REVIEW_ACCOUNT` 与
`WECHAT_REVIEW_PASSWORD`,否则返回 **503 `Review login is not configured`**。

生成并写入:

```powershell
python scripts/set_review_account.py            # 写 ./.env
python scripts/set_review_account.py --dry-run  # 只看不写
```

脚本会生成 16 位强随机密码、原位替换 `.env` 中的三个变量
(`WECHAT_REVIEW_ACCOUNT` / `WECHAT_REVIEW_PASSWORD` / `WECHAT_REVIEW_PHONE`),
然后提示重启服务。**密码只显示一次**,请立即记录。

## 内容提现体验路径

1. 打开小程序，点击首屏“体验完整功能”，无需手机号授权或其他环境配置。
2. 系统会直接进入“收益”页面。
3. 页面展示可提现余额、冻结金额、累计收益、提现记录和历史流水。
4. 提现金额默认填写 `1.00` 元，也可手动修改。
5. 点击“申请提现”，页面弹窗展示申请金额、申请编号及“财务审核中”状态。
6. 关闭弹窗后，可在“提现记录”中查看刚提交的申请。

也可以点击“账号密码登录”，使用上述审核账号进入同一功能页面。

如果审核系统直接打开 `pages/repairer/earnings/earnings`，页面也会自动进入独立审核账户，不会跳回登录页。

该账号只使用演示数据，不涉及真实用户信息或真实资金。审核账户与普通演示师傅完全隔离，每次重新登录会自动退回上一笔待处理测试申请并恢复 `100.00` 元可提现余额；单次体验最多提交 `5.00` 元。

> 本轮鉴权收口后,审核账号登录会走 `require_staff_or_self`,收益页读取的是该审核用户自己的钱包
> (本地实测:登录 → `available_balance=100.00`)。
