# 立即修 H5 工作台

## 入口

- 本地后端挂载路径：`/h5/`
- 静态文件：`h5/index.html`、`h5/styles.css`、`h5/app.js`
- API 前缀：沿用当前 FastAPI 的 `/api/v1`

## 角色页面

- 客户端：快速报修、我的订单、服务套餐、客服工单、钱包/提现。
- 师傅端：待接工单、我的工单、提交服务单、收入钱包、师傅资料。
- 管理端：概览、订单、用户、师傅、门店、套餐、财务、客服、告警。

## 部署建议

生产部署推荐让 Nginx 直接托管 `h5/` 静态文件，并将 `/api/`、`/health`、`/metrics` 反向代理到 FastAPI。
这样 H5 和 API 可以同域访问，且不影响小程序目录。
